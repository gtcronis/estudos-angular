Tutorial Prático de Angular

1. Instalação do Ambiente

Instale a interface de linha de comando do Angular na sua máquina (processo feito apenas uma vez):

npm install -g @angular/cli

2. Criar e Rodar um Projeto

  • Criar a estrutura: Navegue até a pasta desejada no terminal e execute: 
    ng new nome-do-projeto
    (Selecione CSS como formato de estilo e No para Server-Side Rendering)
  • Acessar a pasta e subir o servidor: 
    cd nome-do-projeto
npm start
    (Acesse http://localhost:4200/ no navegador para visualização do projeto em execução)
  • Atenção ao app.component.html: Ao limpar o código inicial do arquivo principal, nunca remova a tag <router-outlet></router-outlet>. Ela é a "janela" responsável por exibir as telas conforme você navega entre as rotas.

3. Criar Páginas (Componentes)

Para criar uma nova tela no projeto (como a página de disciplinas):

ng g c pages/disciplinas

(Esse comando gera automaticamente a pasta do componente contendo seus arquivos de estrutura, estilo e lógica)

4. Navegação de Páginas (Rotas)

  • Configurar o app.routes.ts: Registre o caminho da URL e o componente correspondente: 
    import { Routes } from '@angular/router';
import { DisciplinasComponent } from './pages/disciplinas/disciplinas.component';

export const routes: Routes = [
  { path: 'disciplinas', component: DisciplinasComponent }
];
  • Link no HTML: Use a tag <a routerLink="/disciplinas"> em vez do href do HTML puro para trocar de tela sem recarregar o navegador.
  • Importação no .ts: Importe a tag no arquivo TypeScript da página para o link funcionar: 
    import { Component } from '@angular/core';
import { RouterLink } from '@angular/router';

@Component({
  selector: 'app-disciplinas',
  standalone: true,
  imports: [RouterLink],
  templateUrl: './disciplinas.component.html',
  styleUrl: './disciplinas.component.css'
})
export class DisciplinasComponent {}

5. O Papel de Cada Arquivo (.html, .css e .ts)

  • .html (Estrutura): Define o conteúdo e a semântica visual da página (títulos, tabelas, caixas <div>, links e botões).
  • .css (Estilo): Cuida da apresentação e do visual (alinhamentos, cores de fundo, sombras, bordas e responsividade).
  • .ts (Lógica): O código TypeScript onde ficam as variáveis, funções, buscas em APIs e as importações necessárias do Angular (como a própria tag RouterLink).
