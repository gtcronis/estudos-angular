# Estudos de Angular

Projetos de estudo em Angular feitos durante o curso de Análise e Desenvolvimento de Sistemas (ADS).

## Projetos

- `angular-components`: [o que o projeto mostra, por exemplo, criação e uso de componentes]
- `angular-contador`: [o que o contador faz]
- `angular-navegacao-e-tutorial`: navegação entre páginas (tutorial e disciplinas) com rotas do Angular

## Tecnologias

- Angular
- TypeScript
- HTML e CSS

## Como rodar

1. Instale o [Node.js](https://nodejs.org).
2. Entre na pasta do projeto que quer abrir, por exemplo:

```
cd angular-contador
```

3. Instale as dependências e inicie o servidor:

```
npm install
npm start
```

4. Abra `http://localhost:4200` no navegador.
